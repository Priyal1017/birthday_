==================================================
MEDIA ASSET DIRECTORY INSTRUCTIONS
==================================================

Drop your personal media files directly in these folders:

1. PHOTOS:
   - Place your JPG, PNG, or WEBP photos in: public/images/
   - Example: public/images/photo1.jpg, public/images/photo2.jpg
   - Update src/config/birthdayData.js to reference "/images/photo1.jpg"

2. VIDEOS:
   - Place your MP4 short videos in: public/videos/
   - Example: public/videos/trip.mp4
   - Update src/config/birthdayData.js to reference "/videos/trip.mp4"

3. MUSIC:
   - Place your background music file in: public/music/
   - Example: public/music/happy-birthday.mp3
   - Update src/config/birthdayData.js to reference "/music/happy-birthday.mp3"
